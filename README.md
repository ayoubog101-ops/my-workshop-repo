# Workshop: My Social App

This repository was created for the workshop. It contains the project board, requirements and starter files for the social posts app.

Prerequisites
- Docker and Docker Compose
- Python 3.10+

How to run with Docker

1. Build and start:

   docker compose up --build

2. The app (placeholder) listens on port 8000.

Run tests

- pytest

See docs/ for requirements and ADRs.
